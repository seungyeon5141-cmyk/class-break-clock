# 쉬는시간 알리미 ⏰

교실 컴퓨터 바탕화면에 띄워 두는 **자동 시계(쉬는 시간 알리미) · 타이머 · 학생 뽑기 · 디데이 · 돌림판** 프로그램입니다.
연보라·핑크 파스텔 테마이고, 큰 제목·시계 숫자는 **페이퍼로지**, 버튼·메뉴 같은 화면 글자는 **프리텐다드**, 친근한 안내 문구는 **온글잎 의연체**를 씁니다.

## 주요 기능

### 🕘 메인 화면 · 자동 시계
- 가운데에 `시:분:초` 실시간 시계와 큰 날짜, 그 아래에 “수업 시간 1분 전에는 자리에 앉아 교과서를 준비합니다” 문구 (설정에서 바꿀 수 있어요)
- **요일별 시정**: 월화목금과 수요일처럼 시정이 다르면 시정을 여러 개 만들고, 요일 버튼으로 각 시정을 쓸 요일을 고르세요. 같은 시정인 요일은 한 번만 입력하면 돼요 (새 시정은 기존 시간표를 복사해서 시작할 수 있어요)
- 어느 시정에도 없는 요일(예: 토·일)에는 종이 울리지 않아요
- **설정 › 시간표**에 교시별 시작·끝 시각을 넣으면 그 사이가 자동으로 쉬는 시간이 됩니다
- 줄마다 **종류(수업/점심)**를 정할 수 있어요. 점심 줄은 종 없이 “점심 시간”으로 표시되고, 끝나기 1분 전 알림은 그대로 울려요
- ⠿ 손잡이를 끌거나 ▲▼로 **교시 순서를 옮길 수 있고**, 옮기면 수업 길이·쉬는 시간을 유지한 채 시간이 자동으로 맞춰져요 (끌 수 있어요)
- **안내 음성**: 미리 녹음해 넣은 **또렷한 젊은 여성 음성**으로 크게 안내해요 (설정 › 알림·소리에서 컴퓨터 기본 음성으로 바꿀 수 있어요)
- **수업 시작 1분 전**: 시계가 **빨간 글씨 카운트다운으로 깜빡이며 바뀌고**, “띵동” 알림음과 함께 “수업 시간 1분 전입니다” 음성 안내가 나옵니다
- **수업 시작**: 귀여운 시종음, **쉬는 시간 시작**: 쉬는 시간 종소리
- 메인 화면의 **수업 시작종 / 쉬는 시간종 / 1분 전 알림** 버튼으로 바로 ON/OFF
- 종소리 종류: 귀여운 실로폰 · 오르골 · 딩동댕동 학교종 (설정에서 미리 듣기 가능)
- 알림이 울리면 창을 맨 앞으로 띄워 줍니다 (끌 수 있어요)

### ⏳ 타이머 / 스톱워치
- 1·2·3·5·10·20·30·40·50분 빠른 설정, 숫자 직접 입력, ±1·5·10분 (실행 중에도 가능)
- 종료 5초 전 경고음, 타이머 제목, 크게 보기, 스페이스바로 시작/정지
- **크고 강렬한 종료음 4가지**: ⏰ 따르릉 알람시계(기본) · 📟 삐삐삐삐 디지털 · 🚨 사이렌 · 🎺 빠바바밤 빵빠레 (▶ 미리 듣기, 울리는 중 숫자를 누르거나 타이머 창을 닫으면·Esc를 누르면 멈춤)
- 스톱워치 기록(랩): 오른쪽 칸에 구간 시간과 누적 시간이 쌓여요

### 🎲 뽑기
- **학생 뽑기 / 모둠 선출 / 직접 입력 선출** 세 가지 방식, 한 번에 뽑을 개수, 뽑힌 항목 제외, 추첨 효과 켜기·끄기
- **➕ 이어서 뽑기**: 한 번 뽑은 뒤 누르면 이번 판에서 뽑힌 후보를 빼고 계속 뽑아요. 앞에서 뽑힌 순서가 위에 작게 남아요
- **🔄 다시 뽑기**(민트색): 언제든 누르면 뽑힌 후보를 모두 되돌리고 처음부터 새로 뽑아요. 뽑힌 기록은 그대로 남아요
- 모두 한 번씩 뽑히면 🎉 안내가 나오고 다시 뽑기 버튼이 깜빡여요
- **뽑힌 기록은 탭마다 따로** 저장돼요 (학생 뽑기 / 모둠 선출 / 직접 입력 선출). 초기화도 지금 탭만
- 모둠 선출: 모둠 수(2~12)만 정하면 “○모둠”을 뽑아요
- 직접 입력 선출: 한 줄에 하나씩 최대 60개
- **설정 › 학생 명단**에서 CSV 파일(`번호,이름[,성별]`)을 불러오면 바로 사용
- 엑셀에서 저장한 CSV(EUC-KR)와 UTF-8 모두 자동 인식
- 여러 명 동시 뽑기, 뽑힌 학생 제외, 결석 학생 제외(이름 클릭), 남/여만 뽑기, 뽑힌 기록
- 뽑기 화면 오른쪽 아래 ⚙️ **설정 › 제외 번호 지정**: 전학생 번호 등을 빼고 뽑기. 제외한 번호는 학생 명단·인원 수·뽑기 애니메이션·돌림판 어디에도 나타나지 않아 학생들이 알 수 없어요

### 🏁 뽑기 레이스
- 마블 룰렛처럼 이름 구슬이 위에서 떨어지며 페그 숲 · 지그재그 미끄럼틀 · 바람개비 · 범퍼 · 깔때기를 지나 **결승선 순서대로 순위**가 매겨져요
- 참가자: 학생 명단(결석·제외 번호 자동 제외) 또는 직접 입력 (최대 60명)
- 당첨 순위: 1등 / 꼴등 / 직접 정하기(N등). 카메라가 당첨 자리의 구슬을 따라가요
- 전체 맵, 실시간 순위, 제목, 속도 1x·2x·3x, 효과음 켜기·끄기, 3·2·1 출발 카운트다운
- **🎵 신나는 8비트 BGM**: 레이스가 달리는 동안 기본으로 흐르고, 결승이 가까워질수록 빨라져요. 🎵 버튼으로 끄고 켤 수 있어요 (앱 안에서 직접 합성해 저작권 걱정 없음)

### 📢 긴급 팝업
- “조용히 합시다”처럼 갑자기 알릴 내용을 **화면 가득 아주 크게** 띄워요 (기본 글꼴: 프리텐다드 Black)
- 자주 쓰는 문구를 저장해 두고 한 번 눌러 바로 띄우기, ★로 문구 추가
- 색 6가지, 글꼴 4가지, 자동으로 닫기(직접 닫기·5초·10초·30초·1분), 띄울 때 알림음
- 화면 아무 곳이나 누르거나 Esc를 누르면 닫혀요

### 📌 공지사항 (포스트잇)
- 하단 **공지** 버튼 › ＋ 로 공지를 쓰면 메인 화면에 **포스트잇**으로 붙어요 (줄바꿈 가능, 최대 20개)
- **포스트잇 색**: 파스텔 컬러칩 10가지 + 사용자 지정 색
- **글자 색**: 12가지 + 사용자 지정 색, **글자 크기**: 16~96px
- **글꼴**: 페이퍼로지 / 프리텐다드(Thin~Black 9가지 굵기) / 온글잎 의연체 / 카페24 단정해 · 당당해 · 아네모네 · 써라운드 · 써라운드 에어 · 슈퍼매직(보통·굵게)
- **크기 조절**: 메인 화면에서 포스트잇 오른쪽 아래 모서리를 끌어 크기를 마음대로 바꿔요. “크기에 맞춰 글자 자동 조절”을 켜면 글자도 함께 커지고 작아져요
- **정렬**: 왼쪽 · 가운데 · 오른쪽 · 양쪽, **글머리 기호**: • ◦ – ✔ ★ ♥ ▶ 📌 1. ①
- 포스트잇은 **끌어서 원하는 자리로 옮기고**(위치 저장), **두 번 눌러 바로 수정**
- **화면에서 보기**로 붙였다 뗐다, “위치 처음으로”로 오른쪽 위에 다시 모으기

### 📅 디데이
- 제목(20자) · 날짜 · 배경 색 · 글자 색 · 글자 위치(상단/하단)
- 배경 색: **파스텔 키컬러 10가지 + 사용자 지정 컬러칩 + 투명**
- **화면에서 보기**를 켜면 메인 화면 **왼쪽 위에 고정**, 끄면 숨김 (최대 50개)

### 🎡 돌림판
- 한 줄에 하나씩 항목 입력, 학생 명단 불러오기, 섞기, 당첨 항목 빼기

### 🖥️ 컴퓨터와 함께 켜지고 꺼지기
- **컴퓨터를 켜면 자동 실행** (설치 후 처음 실행할 때 기본으로 켜짐, 설정 › 일반 또는 트레이 메뉴에서 끌 수 있어요)
- 컴퓨터를 끌 때는 설정과 창 위치를 저장하고 자동으로 종료됩니다
- ✕ 버튼을 누르면 작업 표시줄 트레이로 숨어서 종소리는 계속 울립니다 (트레이 아이콘 우클릭 › 완전히 종료)
- 📌 항상 위에 고정, 전체 화면, 최대화

### 🎨 디자인
- 하단 메뉴·종소리 버튼·창 제목·상태 표시에 3D 파스텔 아이콘 (src/assets/icons)
- 메인 화면·설정은 연보라·핑크, 각 도구 창은 저마다 다른 파스텔 색 (타이머 하늘·민트, 뽑기 피치·코랄, 레이스 라임·청록, 공지 레몬·오렌지, 팝업 체리, 디데이 페리윙클, 돌림판 라일락)

## 설치 파일 만들기

### 방법 1: GitHub Actions (추천)
1. 저장소의 **Actions › 설치 파일 만들기 › Run workflow** 실행
2. 끝나면 실행 결과 아래 **windows-installer**를 내려받으면 `ClassBreakClock-Setup-1.13.0.exe`가 들어 있어요
3. `v1.13.0` 같은 태그를 푸시하면 **Releases**에도 자동으로 올라갑니다

### 방법 2: 내 컴퓨터(Windows)에서
```bash
npm install
npm run dist:win     # release/ClassBreakClock-Setup-1.13.0.exe 생성
```

> 코드 서명 인증서가 없어서 처음 실행할 때 Windows SmartScreen이 “알 수 없는 게시자”라고 경고할 수 있어요.
> **추가 정보 › 실행**을 누르면 설치됩니다.

## 개발

```bash
npm install
npm start        # 앱 실행
npm run check    # 자바스크립트 문법 검사
```

```
main.js          Electron 메인 (창, 트레이, 자동 실행)
preload.js       화면에 노출하는 안전한 API
src/index.html   화면
src/css/         파스텔 테마
src/js/          clock(시간표·자동 종), notice(공지 포스트잇), popup(긴급 팝업), race(뽑기 레이스), timer, picker, dday, roulette, settings, sound(종소리 합성)
src/vendor/      matter.min.js (물리 엔진, MIT)
src/fonts/       페이퍼로지, 프리텐다드, 온글잎 의연체
sample/          학생 명단 CSV 예시
```

데이터(시간표, 학생 명단, 디데이 등)는 이 컴퓨터의 앱 데이터 폴더에만 저장되고 인터넷으로 보내지지 않습니다.
설정 › 일반에서 백업 파일로 내보내고 다른 컴퓨터에서 불러올 수 있어요.
